📘 Student Notes Sharing System 📌 Project Overview

The Student Notes Sharing System is a Django-based web application that allows students to upload, browse, and download academic notes. The platform provides a clean and modern interface with enhanced UI/UX using custom CSS and JavaScript.

🚀 Features

User registration, login, and logout

Upload notes (PDF / DOCX)

Subject-wise organization of notes

Card-based notes listing with live search

Download count tracking

Responsive and modern UI (Bootstrap)

Dark mode toggle

Client-side validation and interactions using JavaScript

🛠️ Tech Stack

Backend: Django (Python)

Frontend: HTML, CSS, Bootstrap

JavaScript: Vanilla JS

Database: SQLite

Authentication: Django Auth

File Handling: Django Media Files

📂 Project Structure StudentNotes/ ├── notes/ ├── users/ ├── templates/ ├── static/ │ ├── css/ │ └── js/ ├── media/ └── manage.py

🎯 Learning Outcomes

Django models and relationships

Authentication and authorization

File upload and media handling

Template inheritance

Static files management

Enhancing UX with JavaScript
